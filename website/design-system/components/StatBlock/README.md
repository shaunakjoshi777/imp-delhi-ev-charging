# StatBlock

One big figure with a caption that carries its unit and source.

- **Provide:** the figure (already formatted) and a caption with unit and source.
- **Spec:** figure in the `figure` style (`figure-phone` at 375px), tabular numerals, `ink`. Caption in `caption`, `ink-2`.
- **Never** colour-code values, and never set one method's figures beside another's. In the explorer, Figures shows one method at a time.
