# MapTooltip

Shows details when you hover or tap something on the map.

- **Station:** method, site ID, area, and whether it is shared.
- **Demand square:** demand weight (out of 1,000) and population.
- **Spec:** `raised`, 1px `border`, `radius-control`, 14px text (`caption`). Labels in `ink-2`, values in `ink`.
- Must also open on tap and on keyboard focus.
