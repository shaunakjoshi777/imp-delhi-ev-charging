# SharedBadge

Marks a site that the methods share.

- **Spec:** small double-ring icon in `consensus` (`ink`) with the word "Shared", on `raised`, `radius-control`.
- A shared site is a grid station that MCLP (3 km sites) also chooses and that has a K-means station within 1 km.
- Always include the word. The ring alone is not enough.
