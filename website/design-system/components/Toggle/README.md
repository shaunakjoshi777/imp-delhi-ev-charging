# Toggle

A checkbox with a label, used under the map for map layers.

- **Provide:** the label and on/off state. Under the map: Demand layer, Coverage rings, Existing chargers, then a "Reset" button.
- **Spec:** 44px touch target (`touch-target`), label in the `ui` style. Checked box fills `accent` with an `on-accent` tick.
- Use a real `<input type="checkbox">` so it works by keyboard.
