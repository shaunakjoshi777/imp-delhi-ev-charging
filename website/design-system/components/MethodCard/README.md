# MethodCard

Explains one siting method: what question it answers, its steps and its settings.

- **Provide:** method (sets the top rule colour), name, the question it answers, numbered steps, settings, citation.
- **Spec:** `surface` card, 1px `border`, `radius-panel`, 3px top rule (`method-rule`) in `grid`, `kmeans` or `mclp`. Name in `h3`. Steps in `ui`.
- **All three cards are the same size** and always appear in the order Grid, K-means, MCLP. No strengths, weaknesses, scores or badges.
- Stack to one column on phones.
